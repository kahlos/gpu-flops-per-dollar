Methodology

  1. AI TFLOPS = dense max(FP4, INT4) from TPU Matrix Performance. Ampere has no FP4 hardware, so dense INT4 is used; sparse 2:4 (2×) plus INT8/FP16/BF16/TF32 tensor and FP32/FP16 theoretical are shown alongside. Where Matrix numbers are absent, the highest Theoretical Performance number is used.
  2. Price = SecondHandSilicon trailing-30-day mean of used eBay sold listings (API stat + independent recompute from raw listings in each JSON). Samples below 10 listings are flagged thin.
  3. Metric = AI TFLOPS ÷ price. Also stored: VRAM/$, bandwidth/$, W/TFLOP, sparse variant.

Caveats & provenance

  • TPU specs are fully live: fetched with headed Chromium (playwright-cli solves the PoW; headless gets a hard 403). Raw pages archived as zstd blobs in gpu.db:raw_pages; each run diffs live values against the curated baseline (tpu_discrepancies, currently empty after fixing 13 real errors: PSU ratings, GA106 12.0B transistors, RTX 3050's 32 ROPs / PCIe x8 / 8-pin, 3080 die stepping).
  • RTX 3060 8GB has no TPU reference page (verified in the live DB table — AIB-only launch); its record is sibling-derived, memory per TPU news 300248.
  • 3090/3090 Ti carry a large VRAM premium (24 GB) — worst TFLOPS/$ but best for large local models.
  • SHS 30-day means move daily; every record is timestamped (pricing.fetched_at).
