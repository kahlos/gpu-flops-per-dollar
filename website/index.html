How to read this

  1. Never mix bit-widths. FP4 throughput is ~2× INT8 on the same Blackwell die; INT4 is ~2× INT8 on Ampere/Ada. Ranking FP4 cards against INT4 cards is ranking different arithmetic. Use the precision tabs — each leaderboard only contains cards with hardware for that format.
  2. Metric = selected precision TFLOPS ÷ trailing-30-day mean (used eBay sold). Sparse toggles structured 2:4 (2×) where the architecture supports it; otherwise sparse = dense.
  3. Practical picks: INT8 is the most cross-vendor comparable inference format; FP16/BF16 for training-adjacent work; FP32 for fallback / gaming-class cards without tensor cores.
  4. Thin data (n < 10 sales in 30d) is badged, never silently dropped unless you tick “hide thin data”.

Provenance

  • TPU specs are fully live (headed Chromium). Raw pages archived as zstd blobs in gpu.db:raw_pages; sibling-derived SKUs (no TPU reference page) show “sibling-derived”, never a guessed URL.
  • SHS 30-day means move daily; every record is timestamped. Both used and new windows are stored — switch price basis above.
  • Cards without tensor hardware fall back to theoretical FP32 and are badged theoretical fallback.
